## Lo que sigue

El filtro del índice es una propuesta pendiente, no una función implementada.
El TODO especifica conservar padres, ignorar mayúsculas/acentos, mostrar el recuento,
Enter a la primera coincidencia, Escape para limpiar y flecha abajo hacia el árbol.
Su implementación va después de validar el resaltado con documentos reales.

Se mantiene el bloque de validación cotidiana y rendimiento antes de preparar
otra entrega portable. Las pestañas siguen reabriendo un único documento en el
worker; el I/O de archivos remotos puede demorar el cambio. Los metadatos de
versión/fecha y el ZIP se deben revisar al cortar la próxima entrega.

Se corrigieron descripciones antiguas del tema en la documentación para reflejar
que el modo del sistema y las opciones nuevas ya existen. No se modificó el código
funcional del lector como parte de esta revisión.
